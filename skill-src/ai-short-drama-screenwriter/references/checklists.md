# 短劇審閱與修改清單

## 優先問題

1. 問題：具體指出失效之處。
   - 依據：對應故事節點、場次或臺詞。
   - 影響：說明為何妨礙理解、情緒或節奏。
   - 修改：提供可執行的修正方向。

## 建議保留

只列真正有效且應在修改時保留的元素。

## 題材與觀眾

- [ ] 題材、核心前提與目標觀眾清楚且彼此相符。
- [ ] 類型承諾在開場與主要事件中可被觀眾辨識。

## 結構與節奏

- [ ] 全劇與單集都有明確目標、阻力、轉折與落點。
- [ ] 每集的篇幅符合指定時長，沒有重複或停滯段落。

## 角色動機與連貫性

- [ ] 角色的選擇由已建立的目標、壓力或新事件支撐。
- [ ] 角色轉變有連續的可見行動與代價。

## 場次與衝突

- [ ] 每場有角色目標與阻力，並改變資訊、關係、目標、風險或情緒。
- [ ] 衝突隨場次推進而升級，不只由角色說明。

## 臺詞與潛臺詞

- [ ] 臺詞符合角色關係與當下目的。
- [ ] 關鍵資訊盡量由行動、反應、迴避或試探承載。

## 反轉與鉤子

- [ ] 反轉有前文線索，回看時合乎人物與因果。
- [ ] 集尾鉤子帶來下一步問題、風險或不可逆代價。

## 可拍性與製作限制

- [ ] 場景、角色、道具與事件符合已指定的預算與製作條件。
- [ ] 動作能被看見或聽見，不依賴難以拍攝的內心解說。

## 格式與最終修改

- [ ] 集標題、場次標頭、角色名稱、臺詞與畫面文字一致。
- [ ] 要求標準短劇或標準豎屏格式時，每場標頭皆含場次、內景／外景、地點與時間。
- [ ] 修改優先處理妨礙理解、情緒或節奏的問題，並保留有效元素。
